# Adv_Web_Final_Project

ระบบจัดเส้นทางและแบ่งงานไรเดอร์สำหรับร้าน "ข้าวกล่องเดลิเวอรี ส่งด่วนมื้อเที่ยง"
ออเดอร์ 20–30 รายการต่อวัน ไรเดอร์รับไม่เกินคนละ 3 ออเดอร์ ออกจากร้าน 11:30 ต้องถึงลูกค้าทุกคนก่อน 12:30
และเลือกเส้นทางให้ร้านจ่ายค่าส่งน้อยที่สุด

| โฟลเดอร์ | เทคโนโลยี | รายละเอียด |
| --- | --- | --- |
| [`angular-router/`](angular-router/README.md) | Angular 22 | หน้าเจ้าของร้าน (ลูกค้า ออเดอร์ จัดเส้นทาง) และหน้าใบงานไรเดอร์บนมือถือ |
| [`backend/`](backend/README.md) | Node.js + Express + MySQL | API ลูกค้า ออเดอร์ แผนการส่ง และอัลกอริทึมจัดเส้นทาง deploy บน Render |
